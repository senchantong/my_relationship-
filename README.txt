# Our Love Story — GitHub Ready ❤️

This version includes the five photos you uploaded and uses **relative paths** from the same folder.

## Files
- `index.html`
- `style.css`
- `script.js`
- `memory-1.jpeg` ... `memory-5.jpeg`

## GitHub Pages
Upload **all files in this folder** to the same repository folder (the five JPEG files must stay beside `index.html`).

Then enable GitHub Pages:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**

If the site was already open, refresh it after GitHub finishes deploying.

## Important
Do not put the five `memory-*.jpeg` files inside another folder unless you also change the paths in `index.html` and `style.css`.
